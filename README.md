# ☕ CafeHub – Online Cafe Website

## About
CafeHub is a cafe website where customers can browse the menu and place food orders.

## Features
- Browse food menu
- Customer login
- Place food orders
- Admin page
- Store orders in JSON

## Technologies Used
- Python
- HTML
- CSS
- JavaScript
- JSON

## Project Structure
- `app.py` – Backend
- `templates/` – HTML pages
- `static/` – CSS and JavaScript files
- `orders.json` – Stores order details
- `requirements.txt` – Required Python packages

## How to Run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open the local URL in your browser.
